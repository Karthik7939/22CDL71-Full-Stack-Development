# State and Events in React (TypeScript + Vite)

> **Objective:** Demonstrate React state management and event handling concepts in a TypeScript React environment.

---

## 🚀 Setup & Execution Commands

### 1. Create Application
```bash
npm create vite@latest state-events -- --template react-ts
```

### 2. Navigate and Install
```bash
cd state-events
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to the local URL (e.g., `http://localhost:5173/`).
