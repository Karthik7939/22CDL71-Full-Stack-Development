# Experiment 12: Book Store Client (React + Vite)

Frontend application for the Experiment 12 Full-Stack Book Store.

## 🚀 Setup Commands
```bash
# 1. Install dependencies
npm install

# 2. Run the Vite development server
npm run dev
```

> **Note:** Make sure the backend server in `../server` is running on port 5000 before using the frontend application.
